# Street Pomodoro Timer

25分の作業と、ストリートファイター6（© CAPCOM）をプレイする5分の休憩を繰り返すタイマーです。
LLMCon を通して、作業の終わりにゲームの側の準備を進め、休憩の終わりからは操作を段階的に難しくして、作業に戻るのを助けます。

紹介映像（2分25秒）：
https://unryu.org/LLMCon/video/street_pomodoro_timer.mp4

## 使い方

このフォルダは、大規模言語モデルのコーディングエージェント（Claude Code など）に読ませて、
利用者の環境に合わせて組み立ててもらう形で公開しています。エージェントに次のように頼んでください。

> このフォルダの PROMPT.md を読んで、私の環境で Street Pomodoro Timer を使えるようにして。

コントローラの機種、画面の解像度、ゲームの言語の設定などは環境ごとに違います。
これらの違いを、エージェントが参考のコードを直して吸収します。

## オンラインの機能について

作業の終わりにカジュアルマッチ（オンラインの対戦相手の検索）を自動で始める機能は、**既定で切ってあります。**
オンラインの対戦で自動の入力を使うことが、ゲームの利用規約でどう扱われるかを、作者は確かめていないためです。
有効にする場合は、利用者自身がゲームの利用規約を確かめたうえで判断してください。
オンラインの機能を切っていても、タイマー、重ね表示、読み上げ、音量の切り替え、休憩の終わりの操作しにくさは使えます。

## 中身

| 場所 | 何が入っているか |
|---|---|
| `PROMPT.md` | エージェントに読ませるプロンプト。仕様、作者の環境で起きた罠の一覧、進め方、オンラインの機能の扱い |
| `reference/` | 作者の研究室の環境（ROG Ally、Windows、アーケードスティック）で動いているコードの写し |

`reference/` は、作者の手元の非公開のリポジトリから、道具で書き出したものです（バージョンは `reference/version.py`）。
