# KuriCon のアイコン

格闘ゲームの標準的な6ボタン配置（2段3列）を、丸だけで表したものです。

## ファイル

| ファイル | 中身 | 用途 |
|---|---|---|
| `KuriCon.ico` | 角丸の黒地に白い丸 | **これを使ってください。** 実行ファイルとタスクトレイ |
| `KuriCon-256.png` | 同じもののPNG | 説明書や告知に |
| `KuriCon-light.ico` | 白い丸／背景は透明 | 暗いタスクバー専用。試す用 |
| `KuriCon-dark.ico` | 黒い丸／背景は透明 | 明るいタスクバー専用。試す用 |
| `source-sketch.png` | 生成した下絵 | 参考。実物はこれを元に図形として描き直しています |

`.ico` には 16・24・32・48・64・128・256 ピクセルが入っています。

## なぜ下地（角丸の黒）を付けたか

Windows のタスクバーは、利用者が明暗を切り替えられます。**背景が透明だと、どちらか一方で見えなくなります。** 黒い丸なら暗いタスクバーで消え、白い丸なら明るいタスクバーで消えます。

下地を付ければ、どちらでも確実に見えます。試す用として透明背景のものも置いてあるので、**実際のタスクトレイで見比べて判断してください。**

## 作り方

生成した画像をそのまま使うのではなく、**図形として描き直しています。** 生成画像は丸が接していて、16ピクセルに縮めると1つの塊に潰れました。

描き直した版では、円の直径に対して 0.34 のすき間を確保し、上段を少し右へずらしています（アーケードの配置に倣ったものです）。これで16ピクセルでも「丸が6つ、2段に並んでいる」ことが分かります。

作り直す必要が出たときのために、描画のパラメータを書いておきます。

```
すき間  円の直径の 0.34 倍
段のずれ 円の直径の 0.30 倍（上段を右へ）
余白    画像の辺の 0.14 倍（下地つきの場合）
下地の角 画像の辺の 0.22 倍の半径
```
