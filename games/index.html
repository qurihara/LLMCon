CntlLevelConnection — 仮想コントローラ動作確認用

これは LLMCon / KuriCon の仮想コントローラの効果を試すためのゲーム集です。反転・遅延・連打・アナログ変換・マイクなどの改変を掛けると、ゲーム内の右上の入力表示（HUD）と操作感が変わるので、その違いを体験できます。

入力がゲームに届く経路は2つあります。どちらを使っているかは、各ゲームの右上の HUD に出ます。

経路1　WebSocket 直結（推奨）

LLMCon を出力先 websocket で起動すると、コントローラの状態が WebSocket でゲームへ直接届きます。次の3点が利点です。

・パソコンに何台のコントローラがつながっていても、パッドの取り違えが起きません。

・ゲームのタブからフォーカスが外れても、入力は届き続けます。別タブのコントローラのページを操作しながらでも遊べます。

・改変ルール（無効化・差し替え・連打・反転・反応遅延・アナログ変換）を通したあとの状態が届くので、改変の効果がそのまま画面に出ます。

起動のしかた　LLMCon を CntlLevelConnection.exe --sink vigem+websocket のように起動します。vigem と websocket の両方を有効にすると、実際のゲームとブラウザのゲームを同時に動かせます。

つなぎ方　LLMCon と同じ機械で遊ぶなら、このページのゲームをそのまま開くだけで ws://127.0.0.1:8777/vcon/ws につながります。別の機械や別のポートの LLMCon につなぐときは、ゲームの URL に ?ws=ホスト:ポート を付けてください（例：shooter.html?ws=100.119.199.18:8777）。

経路2　ブラウザの Gamepad API

WebSocket から状態が届いていないあいだは、各ゲームはこれまでどおりブラウザの Gamepad API で仮想コントローラを読みます。KuriCon のコントローラのページ（http://127.0.0.1:8788/vcon.html）や物理パッド、マイクで入力すると、ここのゲームが反応します。この経路には次の制約があります。

・ゲームのタブにフォーカスが要ります。ブラウザは、ゲームのタブにフォーカスした状態でボタンが押されるまでパッドを見せません。まずゲームのタブをクリックしてフォーカスを当ててから入力してください。

・パッドの取り違えが起こり得ます。パソコンには複数のコントローラ（外付けUSBパッド・本体内蔵のコントローラ・仮想コントローラ）が同時に見えることが多く、ゲームが読むパッドを取り違えると入力に反応しません。各ゲームは「今まさにボタンを押したコントローラ」へ自動で操作対象を切り替えるので、動かしたいコントローラのボタンを一度押せば、そのパッドに切り替わります。Back ボタンで手動でも切り替えられます。まぎらわしいときは、外付けUSBパッドを外すと分かりやすくなります。

・KuriCon の画面上のコントローラ（別タブの vcon.html）で操作すると、その瞬間ゲームのタブからフォーカスが外れます。そのため、タブを行き来しながらの同時操作は難しくなります。マイク（声でボタン）や物理パッド経由なら、ゲームにフォーカスを当てたまま入力できます。

各ゲーム共通　入力は WebSocket（LLMCon 直結）を優先し、届いていないあいだは W3C Gamepad API を毎フレーム読み取ります（標準マッピング: A=0 B=1 X=2 Y=3 LB=4 RB=5 LT=6 RT=7 Back=8 Start=9 十字=12-15 軸=左スティック）。Gamepad API のときの操作対象は最後にボタンを押したコントローラに自動追従し、Backで手動切替もできます。いま使っている経路は右上のHUDで確認できます。キーボードでも操作できます。
