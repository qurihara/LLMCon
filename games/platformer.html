← ランチャー
操作対象パッド: 入力したパッドに自動追従（手動切替=Back）
操作: 左スティック / 十字 / 矢印・WASD で移動、A(Z) ジャンプ（押しっぱなしで高く、離すと弱まる）、 B(X) 押しっぱなしでダッシュ、Start(Enter) で最初から。 右端のゴール旗を目指す。コインで加点、下へ落ちるとミス。
反転や遅延を掛けると、ジャンプの間合いがどれだけ狂うかを体感できる。
入力は W3C Gamepad API を毎フレームポーリング。標準マッピング（A=0,B=1,X=2,Y=3,LB=4,RB=5,LT=6,RT=7,Back=8,Start=9,十字=12-15,軸=左スティック）。 パッド未検出時は「コントローラのボタンを押してください」を表示。右上 HUD に生入力を表示（反転・遅延・連打・アナログ変換が目で見える）。
LLMCon から WebSocket（ws://ホスト/vcon/ws、既定は 127.0.0.1:8777、?ws=ホスト:ポート で変更可）で コントローラの状態が届いているあいだは、そちらを優先して使う。届かなくなると自動で Gamepad API に戻る。
