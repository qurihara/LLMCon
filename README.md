# LLMCon

**ゲーム本体を変えずに、遊び方を変える。**

LLMCon は、大規模言語モデルから操作できる仮想ゲームコントローラである。外付けのゲームパッドの
入力を受け取り、実行時に決めた規則で改変し、標準のコントローラとしてゲームへ渡す。ゲーム側からは
ふつうのコントローラに見えるので、**対象のゲームのコードには一切手を加えない。**

「だんだん難しくして」「上級者に少しハンディキャップを」「テトリスを右手だけで遊べるように」――
こうした要求を大規模言語モデルが規則に翻訳し、その場で適用する。規則を決めるのは大規模言語モデル、
入力を時間どおりに運ぶのはコードという役割の分担によって、**付加する遅延は良好な条件で約1.5ミリ秒**、
1フレーム（約16.7ミリ秒）のおよそ11分の1にとどまる。

このリポジトリは公開用であり、開発は別のリポジトリで行って、ここへはスクリプトで切り出している。

## 5分で試す

Windows で、仮想の Xbox 360 コントローラとして動かす場合。

1. [ViGEmBus](https://github.com/nefarius/ViGEmBus) を導入する（`installer/README.md` に手順がある）
2. `dotnet build` して `CntlLevelConnection` を起動する（`build-and-run.ps1` でもよい）
3. ブラウザで `http://127.0.0.1:8777/vcon.html` を開く。これが画面上のコントローラである
4. 大規模言語モデルのクライアントから MCP サーバを登録する

```
claude mcp add --transport http llmcon http://127.0.0.1:8777/
```

mac や Linux では、ViGEm が無いので画面を持たないホストを使う。物理のパッドは扱わず、
画面上のコントローラからの入力を WebSocket でブラウザのゲームへ届ける。

```
dotnet run --project CntlLevelConnection.Host -- --port 8777 --sink websocket
```

`games/` に、動作を確かめるための小さなゲームが入っている。

## 何ができるか

**入力を改変する。** デジタルのボタンには、無効化、差し替え、連打、反転を掛けられる。
時間方向には反応遅延を掛けられる。アナログの軸には、感度、不感帯、反転、制限、応答曲線、
軸の入れ替え、回転、変化速度の上限を掛けられる。適用する時刻の範囲（時間窓）を添えれば、
「最初の30秒だけ」「60秒かけて徐々に」といった変化になる。

**コントローラの形を設計する。** 画面上のコントローラは HTML で書けるので、大規模言語モデルが
その場で設計できる。あらかじめ用意したデザインが15種類ある（片手用、極端に小さいもの、
動き回るもの、鍵盤、隠しボタンなど）。

**コントローラをまたいで接続する。** あるコントローラで起きた人間入力の事象を引き金に、
別のコントローラへ作用を送れる。相手には自分自身も指定できる。中央のハブは無く、
各インスタンスが対等に接続し合う。事象の検出と作用の送信は高速なループが担うので、
大規模言語モデルは低頻度の規則を決めるだけでよい。

**記録を参照する。** 何がいつ起きたかは観測専用の記録に残るので、規則が意図どおりに
働いたかを後から確かめられる。

これらはすべて MCP のツールとして公開してあり、**32個のツールが6つの群**に分かれている。
状態を取得する、入力を注入する、入力を改変する、コントローラの形を設計する、
コントローラをまたいで接続する、記録を参照する、の6つである。

## 中身

| 場所 | 何が入っているか |
|---|---|
| `CntlLevelConnection.Core/` | 中核。改変の語彙、MCP サーバ、コントローラ間の接続、画面上のコントローラ |
| `CntlLevelConnection/` | Windows の本体。物理パッドの読み取り、ViGEm への出力、タスクトレイ、マイク入力 |
| `CntlLevelConnection.Host/` | 画面を持たないホスト。mac や Linux で動かすためのもの |
| `games/` | 動作を確かめるための自作の小さなゲーム |
| `profiles/` | 用途を固定する設定のファイル。配布物はこれで機能を絞る |
| `installer/` | 配布物を作るための定義（Inno Setup） |
| `docs/` | 配布物の説明書と、画面上のコントローラのプリセット一覧 |
| `tools/mac/` | mac から遠隔で操作し、ブラウザのゲームを自動で動かして測るための道具 |
| `skills/` | 大規模言語モデル向けの手引き。要求からゲームを選び、規則を書き下し、確かめるまで |

## 使ってよい場面

**対人の場で相手の入力を改変することには、当事者の合意が要る。** 相手の入力を一定時間
無効にしたり、反応遅延を掛けたりできるうえ、掛けられた側は気づきにくい。主催者が拮抗した
勝負を作るために導入し、参加者が了解して参加するのであれば公正さを高める使い方になるが、
相手に知らせずに自分を有利にする使い方は想定していない。

**オンラインの対戦では、そのゲームの規約に従うこと。** 入力を改変する仕組みを不正と見なす
ゲームがある。判断は利用者の責任である。

## この名前について

論文で用いる名前は LLMCon だが、**開発は MCPCon という名前で進めてきた。**
このリポジトリは公開のときに機械的に置き換えているので、開発用のリポジトリや、
以前の記録には MCPCon という名前が出てくる。同じものである。

`CntlLevelConnection` という名前が随所に残っているのは、この実装が
「コントローラレベルゲーム接続」という研究プロジェクトから育ったためである。
