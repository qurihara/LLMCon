# 説明書の画像

`docs/manual.md` から参照する画像を、このフォルダに置きます。

## 名前の付け方

`manual.md` の中に `<!-- 画像N：... -->` という形で、必要な画像とその内容が書いてあります。番号に合わせて、次のように名前を付けてください。

```
01-voice-button.png       画像1
02-invert-diagram.png     画像2
03-downloaded-file.png    画像3
...
15b-steam-exit.png        画像15b
18b-mic-distance.png      画像18b
23b-windowed-game.png     画像23b
```

数字の部分だけ合っていれば、後ろの名前は自由です。

## 撮り方の目安

**必要な範囲だけを写してください。** 画面全体を撮ると、どこを見ればよいか分かりません。メニューなら、そのメニューとその周りだけで足ります。

**指し示す必要があるものには、矢印や枠を入れてください。** とくに画像11（タスクトレイのアイコン）は、矢印が無いとどれのことか分かりません。

**個人の情報が写り込まないように気をつけてください。** ファイル名、フォルダ名、他のアプリの通知などです。

## イラストの作り方

画面を撮るのではなくイラストにしたもの（画像1、2、15、18b、23、23b）は、`tools/draw_manual_figures.py` で作っています。描き直したいときは、次のように実行してください。書き出す先はこのフォルダです。

```
python3 tools/draw_manual_figures.py
```

文字の入る図（画像2、15、23b）は、Python の図形として描いています。画像を生成する仕組みに任せると日本語のラベルが崩れるためです。人や物が出てくる絵（画像1、18b、23）は生成したもので、もとの絵はリポジトリの外にある作業フォルダの `illust-work/gen/` に置いてあります。そのフォルダが無いときは、図形として描く3枚だけが書き出されます。

色は黒・白・赤の3色だけに絞ってあります。新しくイラストを足すときも、これにそろえてください。
