LLMCon · software controller presets

ソフトウェアコントローラのプリセット

LLMCon の仮想コントローラは、HTML と CSS と JavaScript で見た目を記述して差し替えられる。 それぞれのプリセットは「このコントローラがあれば、こういうコンセプトを示せる」という狙いを持つ。 下の各枠は、実際に動くコントローラそのものである（ボタンは押すと沈み、動くものは動き、時間で変わるものは変わる）。

14 presets 切り替え set_controller_preset <name> 配線 data-btn / data-stick 設計者 大規模言語モデル

アプリ起動後、ブラウザで http://127.0.0.1:8777/vcon.html を開き、 set_controller_preset に名前を渡すと、その場でこのデザインへ切り替わる。 入力の配線（data-btn と data-stick）は差し替えられるデザインの外にある土台側が持つので、 デザインのスクリプトが壊れてもボタンは動き続ける。
